# Учебный frontend-проект

## Описание

Проект выполнен в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный сайт учебного интернет-магазина.

## Ссылка на опубликованный проект

GitHub Pages: https://vladimirnikonov07.github.io/kr1-html-css-shop/

## Структура проекта

- `index.html` — главная страница
- `catalog.html` — каталог товаров
- `product.html` — страница товара
- `order.html` — страница оформления заявки
- `contacts.html` — контакты
- `css/style.css` — общие стили
- `js/main.js` — скрипт модального окна
- `images/` — изображения товаров
- `README.md` — описание проекта

## Используемые технологии

- HTML5
- CSS3 (переменные, Flexbox, Grid, позиционирование)
- Небольшой JavaScript для модального окна
- Git / GitHub / GitHub Pages

## Обязательные элементы

- Многостраничность
- Семантическая разметка
- Единая навигация + якорные ссылки
- Карточки товаров
- Таблица характеристик
- Форма заявки
- Модальное окно
- CSS-переменные
- Flexbox и Grid
- БЭМ
- Позиционирование (relative, absolute, sticky, fixed)

## Самостоятельные доработки

- Бейджи «Хит» и «Новинка» (position: absolute)
- Sticky-шапка
- Sticky-фильтры в каталоге
- Кнопка «Наверх» (position: fixed)
- Изображения товаров
- Улучшенные карточки
- Более аккуратная структура CSS
